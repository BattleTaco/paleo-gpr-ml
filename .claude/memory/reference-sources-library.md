paleo-gpr-ml keeps a master annotated bibliography at **`papers/sources.md`**. It indexes:
- Core curated PDFs in `papers/references/` (each has a reading note in `papers/reading_notes/`).
- External PDFs pulled while researching, in `papers/references/external/` (open-access only; paywalled/bot-blocked ones are kept as links).

**Standing rule:** whenever a new paper or source is found or used, **save it** — add a row to `papers/sources.md` with the link, where the PDF lives, and a one-line "why it matters to me." Download the PDF when it's open-access (arXiv/MDPI/PMC); otherwise keep the link. If it's cite-heavy, write a full reading note too.

**This is all explicitly for Michael's learning as well as the research benefit** — the project is as much about him mastering deep learning and learning the GPR/paleontology domain as it is about the paper. So source notes should capture *what each source teaches*, not just bibliographic info, in his voice.
