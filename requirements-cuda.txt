# Requirements for the CUDA training machine (RTX 5090, Blackwell, compute capability sm_120).
#
# Blackwell GPUs need CUDA 12.8 or newer and a PyTorch built against cu128. Stable wheels can
# lag new silicon, so use the NIGHTLY cu128 build. Install in two steps so torch comes from the
# right index and the rest does not drag in a cpu/cu124 torch:
#
#   # 1) PyTorch nightly for Blackwell (cu128). This owns torch/vision/audio:
#   pip install --pre torch torchvision torchaudio \
#       --index-url https://download.pytorch.org/whl/nightly/cu128
#
#   # 2) everything else (this file does NOT pin torch on purpose):
#   pip install -r requirements-cuda.txt
#
#   # 3) the project package, without re-resolving torch:
#   pip install -e . --no-deps
#
# Verify the GPU is actually seen and is Blackwell:
#   python -c "import torch; print(torch.__version__); print(torch.cuda.get_device_name(0)); print(torch.cuda.get_device_capability(0))"
# Expect a 2.x.dev (nightly) version, "NVIDIA GeForce RTX 5090", and capability (12, 0).
# If torch.cuda.is_available() is False or capability is wrong, the wrong wheel got installed.
